# TraceCase identity

The logo is the project owner’s supplied dark teal squircle with a mint dot near its lower-left corner.

The canonical asset is [tracecase-logo.png](assets/tracecase-logo.png), copied unchanged from `Minimal Teal Squircle with Mint Dot.png`. Preserve the supplied colors, proportions, white background, and surrounding space.

It is used in the README, extension icon/popup, and viewer header/favicon. `npm run brand` copies the canonical asset into the application public directories before building; those copies are not separate sources of truth. Release packages include the built application assets.

The interface accent color remains `#0155AB`; it does not recolor the logo.

## Asset provenance

Supplied directly by the project owner. No generation, tracing, recoloring, or background removal was applied to this asset.
