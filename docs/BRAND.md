# TraceCase identity

The logo uses the T-shaped mark supplied by the project owner: a vertical stem with two wings that taper into its sides. The screenshot’s construction grid and background are removed. The approved primary brand color is **`#0155AB`**.

The transparent PNG source is [tracecase-logo.png](assets/tracecase-logo.png). It is used in the README, extension icon/popup, and viewer header/favicon. `npm run brand` copies the source into the application public directories before building; those copies are not separate sources of truth.

Use the mark at its original aspect ratio with clear space. Avoid adding shadows, gradients, ornaments or the earlier play-symbol concept. The CSS primary color is the exact `#0155AB` token; antialiased raster edges may contain intermediate colors.
